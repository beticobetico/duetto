# Duetto
Lyrics meet music. Songwriters post lyrics looking for music, or music looking for lyrics. Others record their proposal over the track, the author picks one, and both sign the co-writing split.

Prototype: data stays on the device (localStorage + IndexedDB) and signatures are simulated. Next: Supabase backend and Solana wallet signing (Mobile Wallet Adapter) for the Solana dApp Store.
